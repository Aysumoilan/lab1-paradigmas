# lab1-paradigmas 


In Task 1, I used a for loop and if/else to check each applicant one by one and add names to the approved and rejected lists. In Task 2, I solved the same problem without loops, using filter, map and reduce instead. The functional code was shorter, but it was harder for me to read at first, especially reduce. In the imperative version I could follow every step, while in the functional version I only described what I wanted.
